# RT-2 论文深度解读

📄 [RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control](https://www.aminer.cn/pub/64c88ca33fda6d7f062685f6)（CoRL 2023，Google DeepMind，被引 3300+）

---

## 一、解决了什么问题

**核心问题：如何让机器人直接继承互联网级预训练模型的知识，实现低层控制的泛化和语义推理。**

论文开篇指出三个矛盾：

1. **数据鸿沟**：最强的视觉-语言模型（VLM）在数十亿网络 token/图像上训练，机器人靠暴力交互收集的数据量永远追不上；
2. **语义与动作脱节**：VLM 只会"说"（语义、标签、文本推理），机器人需要"做"（笛卡尔空间末端执行器命令等底层动作），二者格式完全不同；
3. **已有方案的分层局限**：SayCan、PaLM-E 等工作只把 LLM/VLM 当"高层规划状态机"，把指令拆解成抓取、放置等原语，再交给单独训练的低层控制器执行——低层控制本身无法享受互联网知识的红利。

因此论文提出研究问题：**大型预训练 VLM 能否直接融入低层机器人控制，提升泛化并催生涌现式语义推理？**

---

## 二、提出了什么方案：VLA（Vision-Language-Action）范式

方案出人意料地简洁——**"把动作当作另一种语言"**：

![RT-2 overview：机器人动作被表示为另一种语言，转化为文本 token 与互联网级视觉-语言数据共同训练；推理时将文本 token 反解为机器人动作，实现闭环控制](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6aaf4bdebdc55b0728d18c2a)

1. **动作 → 文本 token**：将机器人动作（末端位置增量 Δ(x,y,z)、姿态增量 Δ(roll,pitch,yaw)、夹爪开合 + 终止位，共 7 维）每一维离散化为 256 个区间，映射到 256 个新 token，与自然语言 token 共用同一词表；
2. **共同微调（co-fine-tuning）**：在机器人轨迹数据（来自 RT-1 的 ~13 万条 episode）与互联网级视觉-语言任务（如 VQA、网页图文）上**同时**微调预训练 VLM，机器人数据占比约 50%；
3. **推理时反解**：模型输出的动作 token 序列被 de-tokenize 回动作值，以 1–3 Hz 频率闭环输出控制指令。

这样网络知识（语义理解、常识推理）就能"无损"地迁移到机器人控制中，催生了 **VLA（视觉-语言-动作）模型**这一全新类别。

---

## 三、网络结构

RT-2 本质上是 **"VLM 骨干 + 动作 token 头"**，没有为机器人设计任何专用模块：

| 组件 | 说明 |
|------|------|
| **视觉编码器** | 继承自预训练 VLM（如 ViT），将相机图像编码为视觉嵌入 |
| **语言骨干** | 预训练 VLM 的 Transformer 解码器，处理指令 + 视觉嵌入，自回归生成 token |
| **动作输出头** | 复用语言解码器，只是把 256 个动作 token 加入词表，**没有任何新增网络结构** |

论文在两个骨干上实例化：

- **RT-2-PaLI-X**（55B 参数）：基于 PaLI-X；
- **RT-2-PaLM-E**（12B 参数）：基于 PaLM-E。

动作空间共 256⁷ 种组合（7 维 × 256 桶），完全通过文本 token 表达，这是整个设计最巧妙之处——**零架构改动，只改数据表示**。

## 四、实验结果

共 **6000+ 次真实机器人试验**，主要结论：

### 1. 泛化性能（vs. RT-1 基线）

![RT-2 两个实例与各基线在已见任务、未见物体、未见背景、未见环境上的总体表现](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6aaf4bdebdc55b0728d18c70)

| 评测类别 | RT-2 | RT-1 | 提升 |
|---------|------|------|------|
| 已见任务 | 82% | 76% | +6% |
| 未见物体 | 88% | 66% | +22% |
| 未见背景 | 75% | 47% | +28% |
| 未见环境 | 73% | 28% | +45% |

在分布内任务上持平略优，而**越远离训练分布，RT-2 优势越大**——说明泛化能力确实来自网络预训练。

### 2. 涌现能力（机器人数据里完全没有的能力）

![RT-2 在涌现技能评测上的定量表现](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6aaf4bdebdc55b0728d18c80)

- **符号理解**：如"把可乐移到 Taylor Swift 图片旁""把香蕉移到德国（国旗）"——RT-2 达 83%，RT-1 仅 12%；
- **人类识别**："把可乐递给戴眼镜的人"——RT-2 达 79%，RT-1 接近 0%；
- **数量/推理**："拿最小的物体""拿离它最近的物体"——RT-2 约 33%，RT-1 约 1%；
- 涌现技能整体：**RT-2（PaLI-X）62% vs RT-1 32%**，且能力随模型规模增大而增强。

### 3. Chain-of-Thought 推理

![RT-2 结合思维链的推理 rollout：先生成计划再生成动作](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6aaf4bdebdc55b0728d18c8f)

在少量"计划+动作"联合标注数据上微调后，RT-2 能先输出语言推理（"Plan: pick rxbar chocolate"）再输出动作。典型例子：
- *"我要钉钉子，场景里哪个物体有用？"* → 识别出**石头**当锤子；
- *"给累了的人选一瓶饮料"* → 选**能量饮料**；
- 多阶段语义推理任务上，CoT 版成功率 **50%**，无 CoT 版仅 **34%**。

## 五、局限与未来扩展

论文明确承认的局限：
1. **不会新技能**：VLM 预训练只带来语义/视觉概念的泛化，机器人的**运动技能仍限于机器人数据中出现过的技能分布**——它学会了"以新方式使用旧技能"，但学不会新动作；
2. 数据在"技能轴"上不够多样；
3. 推理频率低（1–3 Hz），对高速灵巧任务受限。

论文展望的方向及后续实际进展：

| 方向 | 代表工作 |
|------|---------|
| **用人类视频等新数据范式学习新技能** | 后续的跨本体/视频学习路线 |
| **多本体、规模化机器人数据** | [Open X-Embodiment: Robotic Learning Datasets and RT-X Models](https://www.aminer.cn/pub/666be0de01d2a3fbfc8889e0)（ICRA 2024）：21 个机构、22 种机器人本体、百万级 episode，训练出跨本体泛化的 RT-X 模型 |
| **开源 VLA、降低门槛** | [OpenVLA: an Open-Source Vision-Language-Action Model](https://www.aminer.cn/pub/666ba41e01d2a3fbfc11b57b)（CoRL 2024）：基于开源 VLM 训练 7B 开源 VLA，在多个基准上超过 RT-2-X，参数量更小 |
| **更精细的动作表示（超越离散 token）** | [π0: A Vision-Language-Action Flow Model for General Robot Control](https://www.aminer.cn/pub/6854d3d5163c01c850b136fe)（RSS 2025，Physical Intelligence）：用 flow matching 生成连续动作块，把控制频率提升到 50Hz 级，支持长程灵巧任务（叠衣服、收桌子） |

**一句话总结**：RT-2 用"动作即语言"这一极简表示打通了网络知识与机器人低层控制之间的壁垒，验证了 VLM 的语义与推理能力可以涌现到控制策略中——它定义的 VLA 范式至今仍是具身智能的主流技术路线。
