# World Models 论文深度解读

📄 [Recurrent World Models Facilitate Policy Evolution](https://www.aminer.cn/pub/5c2348ceda562935fc1d5633)（NeurIPS 2018，David Ha & Jürgen Schmidhuber，Google Brain + IDSIA，被引 1500+）

这是深度强化学习史上最有影响力的工作之一——"World Models"（世界模型）这个名字的出处。有配套的[交互式在线论文](https://worldmodels.github.io)（2018 年就很超前的做法）。

---

## 一、解决了什么问题

**核心问题：能否让智能体在自己的“想象/梦境”（内部世界模型）中学习，再把学到的策略迁移回真实环境？**

针对的痛点：

1. **样本效率低**：模型无关 RL（如 A3C、DQN）需要与真实环境交互数百万步，像素输入下尤其昂贵；
2. **策略网络过大**：直接从高维像素训练策略需要庞大的网络，且难以用进化策略高效训练；
3. **学习“发生在想象中”的梦想**：Schmidhuber 1990 年就提出“让智能体先学会世界模型、在梦中学策略”的构想，但此前缺乏把 VAE、RNN、进化策略组合起来的可行实证。

## 二、提出的方案

**VAE + MDN-RNN + 简单控制器**的经典组合，最关键的设计思想是**解耦**——大网络无监督学世界模型，小网络由进化策略训练策略：

1. **V（Vision）**：ConvVAE 把每帧图像压缩成低维隐向量 z；
2. **M（Memory）**：MDN-RNN（混合密度网络 RNN）基于历史 (z, a) 序列，预测下一时刻隐变量的**概率分布**（而非单点值）；
3. **C（Controller）**：极简线性策略 `a = W_c [z h] + b_c`，直接把 [z h] 映射为动作；
4. **用进化策略（CMA-ES）训练**：只对 C 的小参数量（CarRacing 上仅 ~867 个参数！）做黑盒进化优化——因为 C 够小，进化策略才跑得动；
5. **“梦境训练”（最出名的实验）**：在 M 生成的假环境里训练策略（甚至故意让世界模型略带缺陷/低温度），再迁移回真实环境。

## 三、网络结构

![整体交互流程：V、M、C 与环境的交互及伪代码](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6a4d23055845f208532c2da2)

```
                 像素观测 x_t
                     │
        ┌────────────▼───────────┐
        │  V: ConvVAE（视觉编码） │  卷积编码 → 隐向量 z_t（如 32 维）
        │  与解码器，无监督训练    │  ← 压缩"现在"
        └────────────┬───────────┘
                     │ z_t ──────┐
        ┌────────────▼───────────┤
        │  M: MDN-RNN（记忆）     │  输入历史 (z, a)，LSTM 输出
        │  预测 P(z_{t+1}|...)    │  混合高斯分布参数 ← 记住"过去"、预测"未来"
        └────────────┬───────────┘
                     │ h_t（隐藏状态）
                     ▼
        ┌─────────────────────────┐
        │  C: 线性控制器           │  a_t = W_c·[z_t; h_t] + b_c
        │  （仅几百~几千参数）      │  ← 决策
        └─────────────────────────┘
```

![ConvVAE（左）与 MDN-RNN（右）的张量形状细节](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6a4d23055845f208532c2ddb)

| 组件 | 结构 | 参数量级 |
|------|------|---------|
| **V** | ConvVAE：卷积编码器 + 反卷积解码器，中间 32 维隐变量 | 较大（无监督训练） |
| **M** | LSTM + 混合密度输出头（256 个高斯分量预测 z 分布） | 较大（无监督训练） |
| **C** | **单层线性映射** | CarRacing 仅 867 参数；VizDoom 用小 MLP |

分阶段训练：先分别无监督训 V 和 M → 再固定它们，用 CMA-ES 进化 C。

## 四、实验结果

### 1. CarRacing-v0（OpenAI Gym）

![CarRacing 训练曲线与累积奖励直方图：906 ± 21](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6a4d23055845f208532c2de6)

- 得分 **906 ± 21**，超过当时其他已发表方法；
- 867 参数的线性策略即可解决该任务——关键在于 [z h] 表征的质量。

### 2. 关键消融：记忆（h）的必要性

![只看 z_t 不看 h_t：632 ± 251；给 z_t 加隐藏层：788 ± 141](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6a4d23055845f208532c2dea)

| 设置 | 得分 |
|------|------|
| 只用 z_t（无记忆） | 632 ± 251 |
| z_t + 一层隐藏层 | 788 ± 141 |
| **z_t + h_t（完整 M）** | **906 ± 21** |

证明 RNN 的**时序记忆/预测信息**是性能的主要来源——这正呼应"world model facilitates policy evolution"的标题。

### 3. VizDoom“梦境训练”（标志性实验）

![DoomRNN 梦境训练与真实环境迁移：在 100 次连续测试中存活 1092 ± 556 步](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6a4d23055845f208532c2def)

- 世界模型学会模拟 VizDoom 的射击场景（敌人出现时机、弹药）；
- **完全在假环境（梦境）中训练的策略，迁移到真实环境后 100 次试验平均存活 1092 ± 556 步**——证明“在梦里学、到现实用”是可行的；
- 并揭示了一个有趣现象：故意用**欠完美的世界模型**（低温度采样、有噪声）训练反而更稳健——与现实有细微差异的“梦”提供了隐式正则化，这与人类的“梦境压力训练”假说相映成趣。

## 五、局限与深远影响

**局限**：
1. 世界模型只在短视距任务上验证（CarRacing、VizDoom），长视野误差累积未解决；
2. V、M 分开训练，非端到端（后续 Dreamer 系列解决）；
3. 任务较简单，动作空间低维。

**影响**（对机器人/具身智能脉络的意义）：
- **Dreamer 系列（v1/v2/v3）**直接继承并端到端化了这套 RSSM 思路，成为 model-based RL 的标准范式；
- “世界模型 + 策略”的解耦思想延伸到今天的机器人基础模型——比如你之前看过的 TriVLA（VLA + 情节世界模型），以及 Meta 的 video world model 路线，都可视为这一思想的当代形态；
- 与 Schmidhuber 1990 年"World Models"构想的呼应，使其成为具身智能叙事中被反复引用的源头之作。

**一句话总结**：这篇论文用最简单的三件套（VAE 压缩、RNN 记忆与预测、线性策略 + 进化），第一次系统证明了**在自生成的内部世界模型中训练的策略可以迁移回现实**——它为“世界模型”这个如今在具身智能中无处不在的概念提供了现代起点。
