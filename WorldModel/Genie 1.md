## 一、解决了什么问题

**核心问题：能否只用无标注的互联网视频，学出“可交互、可控制”的世界模型？**

背景与痛点：

1. **世界模型数据依赖**：以往世界模型（Dreamer 系、GameNGen 等）都依赖**有动作标签的环境交互数据**——要么在真实环境里采、要么在已知引擎里玩，成本高、领域窄；
2. **互联网视频是“被动”的**：海量视频里没有人告诉模型“这一帧到下一帧之间角色做了什么动作”，视频与动作的对应关系完全缺失；
3. **梦想**：如果动作可以从纯视频里**自动学出来**，那么整个互联网视频就都成了世界模型的训练数据——环境生成的多样性将不再受限于仿真器。

**成果**：Genie 是首个从无标注互联网视频无监督学出可交互环境的基础世界模型（11B 参数），输入一张图（文生图/照片/手绘草图）即可生成可玩的 2D 世界。

## 二、提出的方案

三个组件的巧妙分工，核心创新是**潜在动作模型**：

### 1. 潜在动作模型（Latent Action Model, LAM）——最重要的贡献
- 观察相邻两帧 (V^t, V^{t+1})，**无监督地推断“帧间发生了什么动作”**，输出 8 个离散潜在动作之一（潜在动作码本自动涌现）；
- 训练目标：给定两帧，学习中间潜在动作 ã，使因果解码器能从第一帧 + 潜在动作预测出第二帧——**动作被隐式定义为“能解释帧间变化的最小信息”**；
- 关键设计：LAM 的 decoder 采用**因果掩码 + 逐帧延迟发布**（前帧可见、后帧遮住），迫使中间的 latent 真正承载动作信息而非拷贝像素。

### 2. 时空视频分词器（ST-tokenizer）
- VQ-VAE + ST-Transformer：把 16 帧 × 分辨率的视频压缩为时空 token（每帧 1024 个 token，码本 8192）。

### 3. 动力学模型（Dynamics Model）
- MaskGIT 式自回归 Transformer：给定历史视频 token + 当前潜在动作，**并行掩码生成**下一帧的 token；
- 用户每次提供一个潜在动作，模型生成下一帧——逐帧循环形成可玩环境。

**副产品（对未来智能体的意义）**：学到的潜在动作空间可以让智能体**从无标注视频模仿行为**（行为克隆），为“从互联网视频训练通用智能体”铺路。

## 三、网络结构

![Genie 训练流程：视频经 ST-tokenizer 离散化，潜在动作模型推断帧间动作，动力学模型迭代预测未来帧](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f840)

![ST-Transformer 架构：L 个时空块，每块含空间注意力层（单帧内 H×W token）、时间注意力层（跨 T 帧）和前馈层](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f842)

```
训练：
  视频帧 V^1..V^T ──► 视频分词器（VQ-VAE + ST-Transformer）
                          │ 离散 token z^1..z^T
  相邻帧对 ──► 潜在动作模型（因果解码器）──► 潜在动作 ã_t（8 选 1）
                          │
                          ▼
  动力学模型（MaskGIT Transformer，12B 级总参数）
  输入：历史视频 token + ã_t ──► 并行掩码预测下一帧 token

推理：
  提示帧（图/草图/照片）──► tokenize ──► + 用户潜在动作
  ──► 动力学模型 ──► 下一帧 token ──► 解码为像素 ──► 循环
```

| 组件 | 结构 | 参数 |
|------|------|------|
| ST-tokenizer | VQ-VAE，含时空 transformer（8 层），帧内 16×16 patch，码本 8192 | ~275M |
| LAM | 因果 Transformer encoder-latent-decoder（延迟帧掩码） | ~2.3B |
| 动力学模型 | LAM 规模的放大版，12 层，MaskGIT 并行生成 | ~11.1B（总规模 11B） |
| 潜在动作空间 | **8 个离散动作**（自动涌现） | — |

训练数据：**Genie-1 数据集**——从 3800 万小时互联网视频中筛出 **3000 万小时**的 2D 平台跳跃类游戏视频（8 FPS、160×90 分辨率），全自动清洗。

## 四、实验结果

### 1. 交互式世界生成（主结果，定性为主）

![从文生图、手绘草图、真实照片出发生成可玩世界](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f862)

- 任意提示帧（Imagen 文生图、手绘草图、真实照片，包括分布外的输入）都能生成角色清晰移动的可玩轨迹；
- **潜在动作语义自动涌现**：训练完全无标签，但 8 个潜在动作在不同提示帧上保持一致且**具有语义**——平台游戏中学出“左、右、跳、无操作”，机器人数据中学出“上、下、左”：

![平台游戏中潜在动作跨帧一致且语义清晰：左/右/跳/无操作](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f89d)

![机器人数据上学到的动作一致性](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f879)

### 2. 涌现的物理与场景理解

![十步轨迹中学会可变形物体（薯片袋）的物理特性](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f86b)

- 学会**可变形物体**的物理（捏薯片袋的形变）；
- **无需 3D 监督即涌现视差（parallax）**：平台跳跃中前景移动快、背景慢——隐式 3D 场景理解。

### 3. 用 Genie 训练智能体（Behavior Cloning）

![BC 结果：Genie 上训练的智能体在未见关卡上成功率高](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f883)

- 用 Genie 生成的环境数据训练 BC 智能体，在 **ProcGen 平台游戏的 100 个未见关卡**上评测：达到约 **60–70% 成功率**（同规模对比基线仅 20–30%），部分设置接近在真实环境训练的专家水平；
- 证明“世界模型 → 训练智能体 → 迁移回真实环境”的闭环可行。

### 4. 缩放实验

![缩放结果：模型越大训练损失越低，2.3B 模型随 batch 增大持续改善](https://open.aminer.cn/hub/amglm_noauth/rag/paper/image/6ab4f9756d1d47c851b4f855)

- 模型从 ~2.3B 到 ~11B，训练损失持续下降，符合缩放律——这直接支撑了“继续放大就能得到更强的通用世界模型”的判断（也就有了后来的 Genie 2/3）。

## 五、局限与意义

**局限**：
1. 分辨率低（160×90）、帧率 1 FPS 生成，动作 8 个离散选择——离真实游戏体验远；
2. 训练数据刻意聚焦 2D 平台游戏（风格单一），长时一致性差；
3. 未做真实 3D 世界（留给 Genie 2）。

**意义**：

| 维度 | 内容 |
|------|------|
| **科学贡献** | 首次证明**动作标签不是必需的**——潜在动作可以从无标注视频自动学出，且自动形成语义化、一致的离散动作空间。这是"互联网视频 = 世界模型训练数据"的关键解锁 |
| **范式意义** | 开创"foundation world model"（基础世界模型）概念：世界模型本身成为可缩放的基础模型 |
| **对智能体训练** | 潜在动作空间为"从无标注视频模仿学习"打开大门——连接了互联网视频与具身智能体训练 |
| **产业延伸** | 直接衍生 Genie 2（3D + 照片级，2024.12）与 Genie 3（实时 720p，2025.08，被称为"world models 新前沿"） |

**在你看过的时间线中的位置**：

```
World Models (2018)      脑内的梦：在世界模型里训练策略
Dreamer v1-v3 (2020-23)  梦里学策略，做成通用 RL 算法
Genie 1 (2024.02)        造梦工厂：从无标注视频自动学出动作与世界
Genie 2 (2024.12)        扩散路线 + 3D + 照片级
Genie 3 (2025.08)        实时交互世界模型
```

Genie 1 是“世界模型进入基础模型时代”的原点——它回答了一个此前被普遍怀疑的问题：**可控的世界动态可以从纯被动视频中涌现**。后续所有视频世界模型（Genie 2/3、GameNGen、Oasis 等）都建立在这个前提上。
